Exercice 2 — Diagramme d’activité de l’envoi d’une facture via Peppol, avec draw.io

Consigne

À partir de la réunion de découverte Peppol et de la documentation LUMEN mise à votre disposition, réalisez un diagramme d’activité pour le même parcours que dans l’exercice 1 : envoyer une facture de vente déjà finalisée via Peppol et consulter le résultat de sa transmission.

Vous pouvez utiliser l’IA pour générer le diagramme, puis l’ouvrir dans l’outil demandé, le vérifier et le corriger.

Diagramme d’activité — draw.io

Représentez le déroulement du parcours avec :

  • un début et des fins clairement identifiables ;
  • des couloirs distinguant les responsabilités du gestionnaire, de LUMEN et du service externe ;
  • des activités formulées par des verbes d’action ;
  • des décisions avec des sorties explicites ;
  • le parcours nominal et les mêmes alternatives que dans le diagramme de séquence.

Réalisation : utilisez l’IA pour proposer le diagramme et, si vous le souhaitez, générer un XML natif draw.io. Ouvrez le fichier dans draw.io / diagrams.net, puis ajustez les formes, les textes et les flèches. Vous pouvez aussi construire le diagramme directement dans draw.io avec l’aide de l’IA. Le résultat doit rester éditable ; une image seule ne suffit pas.

Fichier à remettre : Activite_envoi_facture_Peppol_Groupe_XX.drawio.

Vérification avant remise

Vérifiez directement dans votre diagramme que :

  • il représente le même périmètre, les mêmes décisions et les mêmes résultats possibles que votre diagramme de séquence ;
  • les règles représentées correspondent aux sources ; les éléments non confirmés sont signalés par des notes ;
  • une réponse absente n’est pas assimilée à un refus certain ou à une transmission réussie ;
  • la facture finalisée conserve son numéro et ses montants, et la transmission ne crée pas de paiement ;
  • le fichier draw.io s’ouvre avec ses éléments modifiables ;
  • les textes, les flèches et les conditions sont lisibles.

Remettez uniquement le fichier modifiable. Aucun document d’analyse, compte rendu, export ou note complémentaire n’est demandé.
