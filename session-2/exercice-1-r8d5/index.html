Exercice 1 — Diagramme de séquence de l’envoi d’une facture via Peppol, avec PlantUML

Consigne

À partir de la réunion de découverte Peppol et de la documentation LUMEN mise à votre disposition, réalisez un diagramme de séquence pour le parcours suivant : envoyer une facture de vente déjà finalisée via Peppol et consulter le résultat de sa transmission.

Vous pouvez utiliser l’IA pour générer le diagramme, puis l’ouvrir dans l’outil demandé, le vérifier et le corriger.

Diagramme de séquence — PlantUML

Représentez les échanges entre :

  • le gestionnaire Facturation ;
  • LUMEN ;
  • le service externe Peppol, dont le prestataire reste à sélectionner.

Votre diagramme doit montrer l’ordre des interactions, la demande et la confirmation d’envoi, les contrôles utiles, la transmission et la consultation du résultat. Représentez le parcours nominal et les principales alternatives issues de la réunion, notamment un blocage et un résultat de transmission inconnu.

Réalisation : demandez à l’IA le source PlantUML d’un diagramme de séquence. Affichez-le dans un outil compatible, vérifiez les messages et les branches, puis corrigez le source si nécessaire. Restez au niveau fonctionnel : aucun endpoint API ni composant technique interne n’est demandé.

Fichier à remettre : Sequence_envoi_facture_Peppol_Groupe_XX.puml.

Vérification avant remise

Vérifiez directement dans votre diagramme que :

  • les règles représentées correspondent aux sources ; les éléments non confirmés sont signalés par des notes ;
  • une réponse absente n’est pas assimilée à un refus certain ou à une transmission réussie ;
  • la facture finalisée conserve son numéro et ses montants, et la transmission ne crée pas de paiement ;
  • le diagramme PlantUML s’affiche ;
  • les textes, les flèches et les conditions sont lisibles.

Remettez uniquement le fichier modifiable. Aucun document d’analyse, compte rendu, export ou note complémentaire n’est demandé.

LUMEN est un projet fictif, écrit pour cette formation.
