AI for Business & Functional Analysts · Session 3

Exercise 1 — Add an existing skill and run it on UC-18

Time: 10 minutes.

Brief

UC-18, "Envoyer des rappels manuels ou automatiques" (send manual or automatic reminders), still has open questions. Before you write anything, let a skill written by someone else question you about this need.

The skill is grill-me, published by Matt Pocock on GitHub under the MIT licence. It is a one-line wrapper: it calls a second skill by the same author, grilling, which holds the instructions. grilling asks its questions in short numbered rounds and gives the answer it recommends for each.

  • grill-me: https://github.com/mattpocock/skills/tree/main/skills/productivity/grill-me
  • grilling: https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling

You also need your LUMEN working folder, with its wiki.

Steps

  1. Read the skill before you add it. Open the SKILL.md of grill-me: it only calls grilling. Then open the SKILL.md of grilling. Find its description, then what it tells the assistant to do.
  2. Add it: ask your assistant to do it, with the link. Nothing is installed on your PC: a skill is a folder of text files.
Add the grill-me skill from this link, with the grilling skill it calls:
https://github.com/mattpocock/skills/tree/main/skills/productivity/grill-me

If your assistant cannot add skills, copy the content of grilling's SKILL.md and paste it at the start of a new conversation. The questions are the same; the skill just has no name.

  1. Run it in a new conversation:
Grill me on UC-18, sending manual or automatic reminders.
Read the use case page in the wiki and open-questions.md first.
  1. Answer five questions. Leave one unanswered, on purpose.
  2. Compare the questions it asked with wiki/open-questions.md.

Check

Check directly in the conversation that:

  • the skill fired: the assistant asks its questions in rounds, each with a recommended answer;
  • the assistant waits for your answers and does not answer for you;
  • no question is about a point the wiki already settles;
  • the question you left unanswered stays open: it is not turned into a decision;
  • the answers the assistant recommends are presented as proposals, not as LUMEN rules.

If the skill does not show up once added, check the folder level: SKILL.md must sit directly in the skill folder, with no folder in between.

Nothing to hand in. Keep in mind what you would change in this skill so that it reads the wiki before asking its questions: that is where the next part starts.

LUMEN is a fictional project, written for this training.
