The demo skill: dg-context

The skill shown at the start of the session. It draws a context diagram as an editable draw.io file: the system in the centre, the roles on the left, the outside systems on the right, one labelled flow per exchange, each with its source. For a change that is not built yet, such as the Peppol integration, it shows what exists in navy and what the change adds in dashed orange.

Download the dg-context skill (zip)

What is in it

FileRole
SKILL.mdThe instructions: what a context diagram is, the steps, the fixed layout, the rules
template.drawioThe house style, with one sample of each case. Open it in draw.io to change colours or shapes

There is no script: nothing is installed and nothing is run.

How to use it

  1. Add it to your assistant. In the Claude app: Customize › Skills, then upload the zip.
  2. Open your LUMEN working folder in a new conversation.
  3. Type, for example:

``text /dg-context the Peppol integration, from the Peppol meeting dialogue ``

  1. Open the .drawio file it writes in draw.io: the desktop app or app.diagrams.net.

Good to know

  • The diagram is a draft to review: check each flow against the source named on its label.
  • LUMEN and everyone in it are fictional.
  • On a real project, use only the tools and skills your organisation allows.
LUMEN is a fictional project, written for this training.
